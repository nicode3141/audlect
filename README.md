# Audlect - Vote on music with your friends!

Create music votings, invite your guests and build a playlist together.

### Overview

Choosing music for events shouldn't be a one-person decision.

Audlect helps you to find the best music for everyone of your guests. Everyone can help to shape the playlist.

This project was originally developed for school events. However you can use it for your organization, festival, and other events.

### Features

- Search songs: Using deezer as a music catalogue, you can find almost every song here
- Vote: Vote already submitted songs
- Song previews: Listen to submitted songs
- Voting management: Manage your own votings
- Deadlines: Set up when a voting should start/end
- Reporting: Report songs
- Limits: Limit how many songs, each user can add/like
